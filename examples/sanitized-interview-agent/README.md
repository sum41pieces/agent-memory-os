# Sanitized interview-agent example

This directory is a fully synthetic demonstration. No field was copied from a
real project artifact.

The scenario begins with a historical project location:

```text
C:\Users\demo\projects\interview-agent-v1
```

An explicit current source-of-truth designation selects:

```text
C:\Users\demo\projects\interview-agent-finals
```

The reconciler classifies the new path as `ACTIVE` and the old path as
`SUPERSEDED`. Additional candidates demonstrate an active branch, a future
task (`PENDING`), conflicting port claims (`CONFLICTED`), and a retired
architecture (`DEPRECATED`).

- `synthetic-evidence.json` is generated from the synthetic evidence fixture.
- `synthetic-reconciliation.json` is generated by the production reconciler
  from the synthetic five-status candidate set.

Neither file requires network access, a private repository, an external memory
service, or an API credential.
