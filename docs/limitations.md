# Limitations

- This repository is an alpha and its public interfaces may change.
- It does not write project memory automatically.
- The Current State Model is still in progress.
- The Context Compiler is not implemented.
- The Authority Gate is not implemented.
- There is no Dashboard yet.
- Shadow checks compare pre/post endpoints; they are not an operating-system
  security sandbox or an audit log of every intermediate action.
- Document summaries use bounded deterministic extraction rather than semantic
  or model-based summarization.
- Recorded test results are historical evidence and are never treated as newly
  executed tests.
- The project is intended for local and personal workflows in its current form.
